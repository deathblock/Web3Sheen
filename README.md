# Web3Sheen

Web3Sheen enables decentralized, blockchain-agnostic data exchange through real-time, node-to-node communication and auto-scaling network architecture.

The key benefits of using Web3Sheen include:

- Web3Sheen enables decentralized, blockchain-agnostic data
- exchange through real-time, node-to-node communication
- and auto-scaling network architecture

- javascript

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Sheen.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Web3Sheen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
